# Build 15 — original offline beacon interactions

The original WebGL2 scene now contains three collectible glowing beacons. Action 3 collects within two metres; Action 4 resets the objective. Joystick/WASD movement, jumping and camera controls are unchanged.

This demo is entirely original, asset-free and local. No World of Warcraft assets, quests, accounts or live world packets are used. CI must separately verify browser rendering and a collectible pickup. Physical mobile-device compatibility and actual AzerothCore gameplay remain unverified.
